About The Hypertext Library

This site is devoted to the idea that literature can be analyzed in a hypertextual manner. A certain word or phrase may appear several times for a given book, and we believe there is meaning embedded in the links between the occurrences.

If you are interested in contributing, requesting a book, or learning more, check out the GitHub page.
